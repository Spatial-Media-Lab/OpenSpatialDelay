## Spacing Scale

Standard 8-point scale. The existing codebase uses Tailwind utility classes directly mapped
to these values. Do not introduce custom spacing tokens.

| Token | Value | Tailwind class | Usage |
|-------|-------|----------------|-------|
| xs | 4px | `gap-1`, `px-1` | Inline icon gaps, dot separators |
| sm | 8px | `gap-2`, `px-2` | Button icon gap, tight inline padding |
| md | 16px | `px-4`, `gap-4` | Default element spacing, card inner padding prefix |
| lg | 24px | `px-6`, `py-6` | Card inner padding (feature cards: `p-6`) |
| xl | 32px | `gap-8` | Grid gaps between cards |
| 2xl | 48px | `py-12` | Section top/bottom padding (mobile) |
| 3xl | 64px | `py-16`, `py-20`, `py-24` | Section top/bottom padding (desktop) |

Exceptions:
- Nav height: 56px (`h-14`) — locked, do not change
- Container max-width: 1200px with `px-5 sm:px-8` gutters — locked (20px = 5 × 4, on-grid)
- Hero screenshot polaroid: no padding change needed
- Touch targets (buttons): minimum 44px height enforced by existing `py-3` + `text-[15px]` combo — maintain
