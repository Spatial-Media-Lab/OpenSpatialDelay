# Patreon Tier Copy

> All tiers are **monthly** at launch. Annual billing omitted (RESEARCH.md Pitfall 4 — not eligible
> until page is 3 months live + earning $200+/mo).
>
> Tier names follow a space-exploration theme (Stargazer → Astronaut → Commander → Mission Control),
> mirroring the spatial/3D nature of the Spatial Media Library's tools. Prices and benefit structure
> match D-23 (CONTEXT.md) — only the labels have changed from the original Supporter/Patron/Partner/Founder
> baseline.

## Tier 1 — $3/mo · Stargazer

**Name:** Stargazer
**Price:** $3 / month
**Benefits:**
- Newsletter updates on new Spatial Media Library tools
- Public acknowledgment as a Spatial Media Library supporter

## Tier 2 — $10/mo · Astronaut

**Name:** Astronaut
**Price:** $10 / month
**Benefits:**
- All Stargazer benefits
- Vote on feature priorities for OpenSpatialDelay and future Spatial Media Library tools
- Access to early builds before public release

## Tier 3 — $25/mo · Commander

**Name:** Commander
**Price:** $25 / month
**Benefits:**
- All Astronaut benefits
- 1:1 access via Discord or email
- Early access to future patron-exclusive Spatial Media Library tools

## Tier 4 — $100/mo · Mission Control

**Name:** Mission Control
**Price:** $100 / month
**Benefits:**
- All Commander benefits
- Permanent public thank-you credit in the OpenSpatialDelay About dialog
