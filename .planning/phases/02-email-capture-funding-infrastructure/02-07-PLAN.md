### 1. Color palette — sourced directly from Source/PluginEditor.cpp

This is the plugin's actual palette. Use these values literally in `globals.css` or a Tailwind
theme extension. Do NOT invent colors.

**Backgrounds (dark mode):**
- `--bg-void: #03060b;` — main background (oklch 12% / 0.015 / 260)
- `--bg-panel: #0a0d12;` — cards / panels (oklch 16% / 0.012 / 260)
- `--bg-header: #06090f;` — sticky nav background
- `--bg-recessed: #010205;` — inputs, knob-wells (oklch 9% / 0.012 / 260)
- `--bg-well: #020307;` — filter graph

**Borders:**
- `--border-subtle: #252930;` — primary borders
- `--border-dim: #171b20;` — dim borders, panel edges

- `--text-dim: #6d7279;` — labels, inactive (oklch 55% / 0.012 / 260)

### 2. Typography — Fraunces + Inter (from Design 2)

Exactly as Design 2 had it:
- **Display / headings:** `Fraunces` (Google Fonts). Use `font-variation-settings: 'opsz' 144;`
  for the largest display sizes — Fraunces has variable optical-size axis. Weight 500 (not 700/900).
  Use italic sparingly for emphasis, not for whole headings.
- **Body / UI:** `Inter` variable (Google Fonts). Weights 400/500/600 only.
- **Monospace (for specs tables, code, audio-tech flourish):** `JetBrains Mono` variable.

Import via `next/font/google` in `app/layout.tsx` so all routes get them.

### 3. Layout — hybrid, NO superbold all-caps

Take from Design 1:
- Clean modular grid with card-based feature blocks
- Generous whitespace but not luxurious
- Big-numbers band (stats row with "5 HRTF profiles · 12 semitones · 2048-sample latency · GPL-3.0")
- Large product screenshot in or near the hero

Take from Design 3:
- Use a **single saturated accent as a "color block"** on one section (e.g. a Patreon CTA block
  full-width with `--accent-rose` or `--accent-amber` as background)
- Include the **12-tap rainbow strip** as a thin design flourish — a horizontal band of 12 color
  stripes either below the nav, between sections, or as a list-marker system for features
- Polaroid-style screenshot frames (1px border + subtle shadow + slight -1deg/+1deg rotation)
  are good for the "screenshots carousel" section — BUT keep rotations subtle
- Playful but restrained — NO ALL-CAPS HUGE WORDS. No 120px Archivo Black. No brutalism.

Avoid from Design 3:
- Archivo Black
- Huge all-caps single words as hero
- ASCII dividers with big glyphs

### 6. Accessibility

- All color pairs meet WCAG 2.1 AA for body text (≥ 4.5:1). The palette already has this:
  `--text-primary #e1e5ea` on `--bg-void #03060b` = ~14.5:1.
- Respect `prefers-reduced-motion` — no autoplay animations, polaroid rotations disabled under
  reduced-motion (use a media query in CSS).
- Semantic HTML: `<nav>`, `<main>`, `<section>`, `<article>`. Heading hierarchy without skips.
- `alt` text on every `<Image>`.

### 7. Responsive

- Mobile-first breakpoints: base → `sm: 640px` → `md: 768px` → `lg: 1024px` → `xl: 1280px`.
- Hero headline scales: 36px mobile → 48px tablet → 72px desktop (use `clamp()` if you prefer).
- Features grid: 1-col mobile → 2-col tablet → 3-col desktop (NOT 5-col even on xl; 5 features
  works as 2+3 or 3+2).
- 12-tap rainbow band: stays full-width on all sizes; each stripe is 1/12 of viewport width.
